# Icônes

Les icônes de `ameliorations/` (cases de l'arbre des améliorations sans tour ni pouvoir) viennent de game-icons.net (https://game-icons.net), licence Creative Commons Attribution 3.0 (https://creativecommons.org/licenses/by/3.0/). Le crédit est obligatoire : il est affiché dans le menu Options.

Le fond noir des fichiers d'origine a été retiré ; le jeu les colore selon l'état de la case. Chaque fichier porte l'identifiant de son amélioration (`Perk.get_icon()`).
